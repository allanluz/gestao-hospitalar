# Instruções para Capturas de Tela - Sistema Hospitalar

## 📸 Como Realizar as Capturas

### Configuração Inicial
1. **Resolução**: Configure o navegador para 1920x1080
2. **Zoom**: 100% (padrão)
3. **Modo**: Tela cheia (F11) para capturas limpa
4. **Navegador**: Chrome ou Edge (modo desenvolvedor desabilitado)

### URLs do Sistema
- **Backend**: http://localhost:5000
- **Frontend**: http://localhost:3001

### 📝 Dicas para Boas Capturas

1. **Dados Realistas**: Use registros de exemplo já criados
2. **Estados Ativos**: Mostre funcionalidades em uso
3. **Qualidade**: PNG em alta resolução
4. **Contexto**: Inclua elementos importantes da UI
5. **Consistência**: Mesmo navegador e zoom para todas

### 🔄 Ordem Sugerida de Capturas

1. Inicie pelo Dashboard para mostrar visão geral
2. Siga a ordem dos módulos (01 a 13)
3. Capture primeiro as telas principais, depois detalhes
4. Finalize com notificações e integrações
5. Faça capturas especiais por último

---
**Total Estimado**: 50-60 capturas de tela
**Tempo Estimado**: 2-3 horas para capturas completas
**Resolução**: 1920x1080 (Full HD)
**Formato**: PNG para melhor qualidade
