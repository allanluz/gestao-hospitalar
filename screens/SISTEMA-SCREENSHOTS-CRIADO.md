## 🚀 Como usar:

### 1. Iniciar o Sistema
```bash
# Execute o script de inicialização
cd screens
iniciar-sistema.bat
```

### 2. Fazer as Capturas
1. Use as instruções em `INSTRUCOES-CAPTURAS.md`
2. Siga a ordem dos módulos (01 a 13)
3. Salve na área de trabalho com os nomes corretos

### 3. Organizar Automaticamente
```bash
# Execute o organizador
organizar-capturas.bat
```

### 4. Visualizar Progresso
- Abra `galeria-screenshots.html` no navegador
- Veja o progresso em tempo real
- Acompanhe estatísticas completas
